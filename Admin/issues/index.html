Permanent topics stay in the system. Each month gets new headlines, images, AI-generated articles and an e-paper.

Workflow

  1. Create the new month.
  2. Select permanent topics.
  3. Run source discovery for each topic.
  4. Generate AI draft with verified evidence.
  5. Review and approve.
  6. Publish articles.
  7. Open the e-paper page and Print / Save as PDF.
