# BHARAT FRONTIERS — Assets

This folder contains supporting assets used by the BHARAT FRONTIERS website and publication system.

## Folder Structure

### icons/
Contains website and publication icons.

Examples:
- Search icon
- Menu icon
- Social media icons
- Navigation icons
- Interface icons

### logos/
Contains official BHARAT FRONTIERS branding files.

Examples:
- BHARAT FRONTIERS logo
- The Knowledge Post logo
- Logo variations
- Favicon files
- Monochrome logo versions

### fonts/
Contains approved local font files used by the publication, if required.

### documents/
Contains supporting publication documents and non-article files.

Examples:
- Editorial documents
- Publication guidelines
- Supporting documents
- Reference documents

## Important

The folder structure and website architecture are protected.

Content and media may be managed later through the BHARAT FRONTIERS Admin module.

Do not place article content or article metadata in this folder.

Article data belongs in:

`../Data/`

Article images belong in:

`../Images/articles/`
